# 基于 LangChain 单智能体的用户反馈自动处理系统

自动接收用户反馈，完成分类、情绪识别、知识检索、回复生成、人工转接和处理归档的本地可运行 Agent Demo。

## 核心流程

```
用户反馈 -> 主 Agent 编排 -> 分类/情绪/信息抽取 -> RAG 检索 -> 生成回复 -> 判断是否转人工 -> 保存处理报告
```

## 支持场景

1. **内容社区**：评论 / 私信 / 举报 / 建议
2. **电商售后**：发货、退款、质量、客服投诉

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 配置环境变量

```bash
cp .env.example .env
# 编辑 .env 文件，填入你的 OpenAI API Key
```

### 3. 运行系统

```bash
python main.py
```

或直接测试单个反馈：

```bash
python main.py --feedback "我的订单123456还没发货，催了两次没人理，太离谱了"
```

## 核心能力

### 1. 智能编排
主 Agent 根据反馈内容动态决策调用哪些工具，不固定流程。

### 2. RAG 检索
基于 FAISS 向量数据库检索 FAQ、规则、历史案例。

### 3. 工具调用
6 个核心工具：分类、情绪、抽取、检索、转接、归档。

### 4. 轻量记忆
会话记忆 + 用户历史摘要，本地 JSON 持久化。

### 5. 子代理
理解子代理、回复子代理、执行子代理，模块化处理。

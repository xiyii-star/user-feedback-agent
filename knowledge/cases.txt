【历史案例 - 常见投诉处理话术】

案例1：订单未发货投诉
用户反馈："订单已经3天了还没发货，催了两次没人理"
处理话术："非常抱歉给您带来不便。经查询，您的订单因仓库备货延迟，预计明天发货。我们已为您申请优先发货，并赠送10元优惠券作为补偿。感谢您的耐心等待。"
处理动作：查询订单状态 -> 联系仓库 -> 优先发货 -> 补偿优惠券

案例2：App闪退投诉
用户反馈："你们app一打开就闪退，我是iPhone 14，iOS 17"
处理话术："感谢反馈。iOS 17在部分机型上存在兼容性问题，我们已在紧急修复。临时解决方案：1) 卸载重装 2) 降级到iOS 16。预计3天内发布修复版本，届时会通知您更新。"
处理动作：记录Bug -> 转技术团队 -> 提供临时方案 -> 跟进修复进度

案例3：客服态度投诉
用户反馈："你们客服态度太差了，问了半天都不解决问题"
处理话术："非常抱歉给您带来不好的体验。我们会严肃处理客服态度问题。关于您的问题，我来为您重新处理。请问具体是什么问题？我会尽快为您解决。"
处理动作：道歉 -> 重新处理问题 -> 内部反馈客服 -> 回访确认

案例4：商品质量投诉
用户反馈："收到的商品有破损，要求退款"
处理话术："非常抱歉商品存在质量问题。请您提供商品照片，我们会立即为您处理退换货。您可以选择：1) 退货退款 2) 换货 3) 部分退款继续使用。运费由我们承担。"
处理动作：查看照片 -> 确认质量问题 -> 提供解决方案 -> 处理退换货

案例5：恶意辱骂
用户反馈："你们客服都是废物，垃圾平台"
处理话术："我们理解您的不满，但请注意文明用语。如有问题我们会认真处理，但辱骂行为违反平台规则。请理性表达诉求，我们会尽力解决。"
处理动作：警告 -> 如继续辱骂则禁言 -> 记录违规行为

案例6：广告推广
用户反馈："加我微信XXX，便宜出售各种资源"
处理话术："您的内容涉及商业推广，违反平台规则。内容已删除，请勿再次发布类似信息，否则将封禁账号。"
处理动作：删除内容 -> 警告 -> 记录违规 -> 多次违规则封号

案例7：功能建议
用户反馈："建议增加深色模式，晚上看太刺眼了"
处理话术："感谢您的建议！深色模式已在开发中，预计下个版本上线。我们会将您的反馈转达给产品团队。您可以关注版本更新通知。"
处理动作：记录建议 -> 转产品团队 -> 跟进开发进度

案例8：重复投诉
用户反馈："我已经投诉3次了，为什么还没解决？"
处理话术："非常抱歉让您多次反馈。我查看了您的历史记录，问题是XXX。目前处理进度是XXX，预计XX时间解决。我会持续跟进，有进展立即通知您。"
处理动作：查询历史记录 -> 确认处理进度 -> 加急处理 -> 主动回访
